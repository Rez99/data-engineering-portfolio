# Architecture Decision Records

This directory records significant architecture decisions for Project 2.

Create ADRs in numerical order using descriptive names:

```text
0001-cloud-provider.md
0002-service-mapping.md
0003-orchestration-model.md
```

Copy `template.md` when starting a decision. Use the status `Proposed` while a decision is under discussion and change it to `Accepted` once agreed.
